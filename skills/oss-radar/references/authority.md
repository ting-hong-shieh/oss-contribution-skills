# Radar authority

`oss-radar` may read repositories, issues, pull requests, comments, diffs, contribution rules, CI summaries, and public history.

It may not:

- clone, branch, edit, stage, commit, or run repository code unless a separate LOCAL workflow has been explicitly approved;
- comment, assign, label, claim, review, push, create or edit PRs, rerun CI, or change upstream state.

A recommendation is not authorization. `GO` means “suitable for a separate approved contribution workflow,” not “start coding” and not “claim the issue.”
