# Claude Code adapter

The canonical skills remain portable. This adapter adds deterministic hooks for commands whose safety must not depend on model recall.

## Install cautiously

1. Copy or symlink the three canonical skill directories into `.claude/skills/` or `~/.claude/skills/`.
2. Copy `settings.example.json` to the appropriate project settings and replace `/ABSOLUTE/PATH`.
3. Export `OSS_CASE_FILE` to a runtime JSON case generated by the private control plane.
4. Export `OSS_AGENT_ID` when the case requires a writer or shared-lever lease.
5. Test with harmless and intentionally denied commands before enabling on a live repository.

The example intercepts Bash commands. GitHub connector or other non-shell tool calls must invoke the same gate core in the orchestrator; shell hooks cannot see actions outside the shell.

The optional Stop hook requires `OSS_RUN_RECORD` and blocks completion until the bounded run records its state transition and next action.

The v0.2 runtime case also records execution trust/mode, current-head evidence, independent verification, internal run provenance, and action-scoped shared levers. Ready actions fail closed when those records are stale or inconsistent.
